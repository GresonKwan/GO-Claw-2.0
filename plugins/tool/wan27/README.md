# 视频生成

用于在对话中根据文字、图片或参考素材生成视频。插件使用 GO CLAW 已配置的全局媒体服务，员工侧无需填写密钥、接口地址或模型。

## 工具

- `generate_video_from_text`：根据文字提示生成视频。
- `generate_video_from_image`：根据首帧图片生成视频，也可提供尾帧等辅助素材。
- `generate_video_from_reference`：根据一张或多张参考图片生成视频。

图片可以使用公开的 HTTP/HTTPS 地址，也可以使用本地 PNG、JPG、JPEG 或 WebP 文件。生成结果会下载到本地媒体目录，并同时保留服务返回的原始地址。

## 配置

插件仅开放请求超时时间。媒体服务地址、凭据和内部模型由 GO CLAW 全局配置统一管理。

视频生成失败时，工具会返回错误，不会自动切换到其他模型。
