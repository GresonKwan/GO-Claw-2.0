# 图片生成

用于在对话中生成、编辑或融合图片。插件使用 GO CLAW 已配置的全局媒体服务，员工侧无需填写密钥、接口地址或模型。

## 工具

- `generate_image`：根据文字提示生成图片，可指定尺寸、数量和不希望出现的内容。
- `edit_image`：根据文字提示编辑一张图片，或融合多张参考图片。

参考图片可以使用公开的 HTTP/HTTPS 地址，也可以使用本地 PNG、JPG、JPEG 或 WebP 文件。多图编辑时，可在提示词中用“图一”“图二”指代输入顺序。

## 配置

插件仅开放请求超时时间。媒体服务地址、凭据和内部模型由 GO CLAW 全局配置统一管理。

图片生成或编辑失败时，工具会返回错误，不会自动切换到其他模型。
