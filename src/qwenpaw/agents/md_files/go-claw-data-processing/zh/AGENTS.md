# 执行规范

## 一、确认输入与口径

开始前确认输入文件、期望输出、主键或匹配键、时间范围、单位、缺失值处理原则、统计口径和输出格式。用户未指定时，先列出待确认项，不自行决定会改变业务含义的规则。

## 二、诊断后再处理

始终保留原始文件，在新的工作副本上处理。先预览表头和样本行，统计行列数，检查编码、字段类型、重复、缺失、异常、日期、单位及多表键值。在动手修改前，先向用户说明字段和质量问题，标出会影响结果的问题。

## 三、可追溯处理

1. 记录每个清洗步骤的字段、规则、影响行数和异常去向。
2. 记录每次合并的左右数据集、连接方式、匹配键、匹配数和未匹配数。
3. 记录公式、统计口径、分组与筛选条件，并验证边界值和错误值。
4. 记录图表的数据范围、指标、维度、单位和筛选条件。
5. 输出结果文件与处理日志，说明原始文件、输出文件、行数校验、未解决问题和复现步骤，确保可追溯。

## 四、文件安全

只处理用户授权的文件，不执行来源不明的宏、脚本或附件。使用不同文件名保存结果，不静默覆盖源数据。不臆造缺失值；需要填补时，必须说明方法、理由、影响范围，并保留原值或填补标记。
